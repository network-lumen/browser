SendToken

Send LMN (or a memo-only transfer) from the active wallet, using the embedded wallet UI to prompt/confirm on the user's behalf.
ParameterTypeDescription
rawTxobjectTransaction payload.
rawTx.tostringRecipient bech32 address (also accepts `recipient`).
rawTx.memostringOptional memo/note attached to the transfer (also accepts `note`).
rawTx.amount_lmnnumberAmount in LMN (also accepts `amountLmn`/`amount`).

Returns: Promise<{ok:boolean,data?:any,error?:string}> — Resolves with the broadcast result on success.

Errors:

  • send_failed — Wallet/profile missing, user declined, or broadcast failed.

Pin

Pin a CID (or a `/ipfs/...`, `/ipns/...`, `lumen://...` URL) to the user's Drive, via a confirmation modal.
ParameterTypeDescription
cidOrUrlstring|objectCID/URL string, or `{cidOrUrl|cid|url, name?}`.
optsMaybeobject`{name}`, used when `cidOrUrl` is a plain string.

Returns: Promise<{ok:boolean,data?:any,error?:string}> —

Errors:

  • missing_cid — No CID/URL could be extracted from the input.
  • pin_failed — The user declined, or pinning failed on the host.

resolveUrl

Resolve a `lumen://ipfs/<cid>`, `lumen://ipns/<name>`, `/ipfs/...`, `/ipns/...` or already-absolute http(s) URL into a fetchable gateway URL.
ParameterTypeDescription

Returns: Promise<{ok:boolean,data?:string,error?:string}> — `data` is the resolved URL, or '' if unrecognized.

Errors:

  • resolve_url_failed — The local gateway could not be reached.
